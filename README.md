# Yoga-Fitness

以瀏覽器攝影機進行即時人體姿勢辨識的體感運動專案。

## v0.1 MVP 目標

第一階段聚焦於適合辦公室與居家測試的站姿動作，不包含地板瑜珈。

### 模式

- 🪑 久坐救援
- 🧘 站姿瑜珈
- 🏋️ 基礎健身

### 第一批動作

- 站姿側伸展
- 雙手上舉伸展
- 樹式 Tree Pose
- 戰士二式 Warrior II
- 深蹲 Squat
- 弓箭步 Lunge

## 技術方向

- HTML / CSS / JavaScript
- MediaPipe Tasks Vision - Pose Landmarker
- 純瀏覽器端姿勢辨識
- 不上傳攝影機影像
- 可部署至 GitHub Pages

## v0.1 判定核心

- 全身入鏡檢查
- 左右鏡像顯示
- 33 個人體姿勢 landmark
- 關節角度計算
- 動作姿勢分數
- 即時提示
- 深蹲動作計數
- 靜態姿勢維持計時

## 開發原則

1. 第一版不加入下犬式、平板式、眼鏡蛇式、嬰兒式等地板動作。
2. 先確保手機、平板與電腦一般鏡頭都容易測試。
3. PoseCore 與各動作規則分離，之後新增動作不重寫攝影機核心。
4. 健身與瑜珈共用同一套人體 landmark 與角度計算。

## 隱私

目前設計為瀏覽器端即時分析，攝影機影像不需上傳至伺服器。
